# Ворыпаевское подворье — сайт фермы

Сайт фермерского хозяйства в д. Ворыпаево (г.о. Подольск): баранина и говядина халяль, живые бараны и овцы.

**Сайт:** https://vorypaevo-podvorye.vercel.app

Сайт статический: обычные HTML, CSS и JavaScript, без сборки и без зависимостей. Заказы не хранятся на сервере: покупатель собирает корзину, и заказ уходит одним сообщением в WhatsApp на номер фермы.

## Структура

```
site/                 ← сайт, который опубликован на Vercel
  index.html          главная: о ферме, своя бойня и халяль, товары, как заказать, контакты
  catalog.html        каталог: категории, поиск, корзина
  css/style.css       все стили (цвета — переменные в начале файла)
  js/data.js          ДАННЫЕ: контакты, категории, товары и цены
  js/cart.js          корзина и текст сообщения в WhatsApp
  js/app.js           шапка, меню, нижняя панель на телефоне, карточки товаров
  img/                фотографии
  js/version.js       номер версии (заполняется автоматически при публикации)
vercel.json           настройки Vercel: публикуется только папка site, кэш, заголовки
tools/build-version.mjs  запускается Vercel при публикации, пишет номер версии
tools/serve.mjs       локальный сервер для просмотра, без зависимостей
prototypes/           пять вариантов дизайна, из которых выбирали (v5-hybrid стал сайтом); на сайт не попадают
```

## Как поменять цены, товары, телефон

Всё в одном файле — `site/js/data.js`. В его начале описано каждое поле.

- **Цена:** поле `pricePerKg` (число). Если цена «по договорённости» — `null`.
- **Цена «от»:** `priceFrom: true`. **Вес «от»:** `weightFrom: true`.
- **Примерный вес** одной единицы: `approxKg`. Если вес неизвестен — `null`, тогда корзина пишет «посчитаем после взвешивания».
- **Варианты** (передняя/задняя, баран/овца): `options: ["…", "…"]`.
- **Фото:** положить файл в `site/img/` и указать `img: "имя.jpg"`.
- **Телефон и WhatsApp:** объект `FARM` в начале файла.

## Посмотреть локально

Нужен только Node.js:

```bash
node tools/serve.mjs site 5190
```

Откройте http://localhost:5190. Прототипы: `node tools/serve.mjs` → http://localhost:5180.

## Работа вдвоём и публикация

Над сайтом работают два человека: **Adam7as** (владелец) и **Ali1986470** (соавтор).
Публикация автоматическая: **каждый push в ветку `main` сам выкладывает сайт** на Vercel примерно за минуту.
Заходить в Vercel и запускать что-то вручную не нужно, токены не нужны.

Обычный порядок работы:

```bash
git pull                      # 1. забрать свежую версию перед началом
# 2. внести правки в site/…, проверить локально: node tools/serve.mjs site 5190
git add -A
git commit -m "Что изменил"   # 3. понятное описание — его увидит второй
git push                      # 4. через минуту правка на сайте
```

**Кто и что менял.** История изменений — вкладка *Commits* на GitHub: автор, дата и точные правки каждого коммита.
У каждого коммита на GitHub рядом стоит значок публикации Vercel (✓ или ✗) — нажмите, чтобы открыть публикацию. Список всех публикаций: vercel.com → проект → Deployments.

**Какая версия сейчас на сайте.** В подвале сайта мелко написано «Версия a1b2c3d · дата · автор» — это номер коммита, ссылка ведёт на него в GitHub.

**Откат.** Отменить неудачный коммит: `git revert <номер>` и `git push` — опубликуется предыдущее состояние. Срочно: на vercel.com → проект → Deployments → у нужной прошлой публикации «Promote to Production».

**Если оба правили одно и то же.** `git pull` сообщит о конфликте и покажет оба варианта в файле — оставьте нужный, затем `git add`, `git commit`, `git push`.

### Как устроена автопубликация

Репозиторий подключён к проекту Vercel `vorypaevo-podvorye` (через приложение Vercel в GitHub).
Настройки сборки лежат в `vercel.json` в корне: Vercel запускает `node tools/build-version.mjs` (записывает номер версии в `site/js/version.js`) и публикует только папку `site`.

- **Push в `main`** → публикация на основной адрес.
- **Push в другую ветку или pull request** → отдельная ссылка для предпросмотра, основной сайт не меняется. Удобно показать правку второму человеку до слияния.

Репозиторий публичный: на бесплатном тарифе Vercel только так публикуются коммиты обоих авторов. Секретов в репозитории нет — не добавляйте их в код.

С компьютера владельца можно опубликовать и вручную, из корня репозитория: `vercel deploy --prod` (файлы `.vercel/` и `.env.local` создаются Vercel автоматически и в git не попадают).
